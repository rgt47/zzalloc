# zzalloc 0.2.0

## Correctness fixes

* **`alloc_maximal()` now draws from terminally balanced
  sequences.** The maximal procedure of Berger, Ivanova and Knoll
  (2003) places a uniform distribution on the sequences that both
  respect the maximum tolerated imbalance *and* end with equal arm
  sizes. The backward recursion seeded every terminal imbalance as
  a valid completion, so the sampled set was strictly larger than
  the procedure's: for `n = 6`, `boundary = 2` it drew from 36
  sequences instead of 18, and roughly half of all realizations
  finished unbalanced. Terminal balance is now enforced, and odd
  `n`, which admits no balanced sequence, is rejected rather than
  silently accepted. Sequences generated by earlier versions are
  not draws from the maximal procedure and should be regenerated.

* **`allocation_imbalance()` and `weighted_imbalance()` no longer
  mis-read a factor.** A factor of `"0"`/`"1"` passed the input
  check, because `%in%` compares as character, but was then decoded
  with `as.integer()`, which returns level codes `1`/`2` rather than
  the labels. A balanced allocation supplied as a factor reported an
  imbalance of 3 instead of 0, with no warning;
  `weighted_imbalance()` failed with a misleading complaint that
  only one arm was present. Factors are now converted through their
  labels.

* **`alloc_cara()` rejects covariates named `trt` or `resp`.** Those
  names collide with the columns the working model is fitted on.
  `cbind()` produced two columns of the same name, `$` resolved to
  the covariate, and the fitted formula silently lost the treatment
  indicator (`resp ~ trt + x + trt`) or regressed the response on
  itself. The design then adapted on the wrong variable while
  appearing to run normally.

## Documentation

* `alloc_pocock_simon()` and `alloc_hu_hu()` now record that with
  two arms `measure = "sd"` and `measure = "diff"` give identical
  allocations, the standard deviation of two counts being their
  absolute difference over `sqrt(2)`. Only `"squared"` can order
  candidate assignments differently.

# zzalloc 0.1.0

First release. Seventeen exported functions providing a common
sequential interface to treatment allocation procedures for randomized
clinical trials.

## Allocation procedures

* Unrestricted randomization: `alloc_simple()`,
  `alloc_random_allocation()`, `alloc_permuted_block()`.
* Biased coin designs: `alloc_efron()`, `alloc_wei_urn()`,
  `alloc_smith()`.
* Restricted procedures bounding imbalance in the total sample size:
  `alloc_big_stick()`, `alloc_maximal()`.
* Stratified designs: `alloc_stratified_block()`.
* Covariate-adaptive minimization: `alloc_pocock_simon()`,
  `alloc_hu_hu()`, `alloc_msb()`.
* Covariate-adjusted response-adaptive designs: `alloc_cara()`.

## Interface and diagnostics

* `allocate()` provides the shared sequential entry point and
  `allocation_schemes()` enumerates the available procedures, so that
  one procedure can be substituted for another in simulation studies.
* `allocation_imbalance()` and `weighted_imbalance()` report imbalance,
  the latter using the response-weighted measure appropriate when
  covariates differ in prognostic strength.
